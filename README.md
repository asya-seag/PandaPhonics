Panda Phonics is a mobile application developed using React Native and Expo to support children with early phonics learning.

The app provides an interactive way to explore letter sounds and digraphs, using visual cards and simple interactive features to make learning more engaging.

Getting Started

To run the project locally:

Clone or download the repository.

Open the project folder in your terminal.

Install the dependencies:

npm install

Start the Expo development server:

npx expo start

Scan the QR code using Expo Go on your mobile device, or run the application using an emulator.
